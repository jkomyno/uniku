title: Nanoid
description: Compact, URL-safe random strings with configurable length and alphabet.

---

Nanoid is the compact choice for short URLs, invite codes, and session tokens. Its default alphabet is URL-safe; pass a length or options only when the boundary needs a different shape.

```ts
import { nanoid } from 'uniku/nanoid'

const inviteCode = nanoid()
// 'tCDaBJOIwLpjLMxN_DYdU' (string)
```

`nanoid.isValid()` only checks that a value is a non-empty run of the default URL-safe alphabet. A nanoid carries neither a length nor an alphabet, so it cannot verify either: any length is accepted, and an ID built from a custom alphabet passes whenever that alphabet is a subset of the default one — a hex-only alphabet, for example. Compare `id.length` yourself when the boundary needs one size.
