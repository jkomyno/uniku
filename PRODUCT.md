# Product

## Register

brand

## Users

JavaScript and TypeScript developers use the documentation while choosing an ID strategy, integrating `uniku`, or checking an exact API contract. They need to scan prose, tables, and code on laptops and desktop displays in both bright and dim environments.

## Product Purpose

The documentation teaches developers how to install `uniku`, choose among its ID strategies, use each strategy's callable API, and verify exact signatures and behavior. Success means a reader can find the relevant path, understand the tradeoff, and apply the code without decoding the interface first.

## Brand Personality

Calm, crisp, and technically confident. The interface should feel like clean paper and sharp ink in light mode, and a low-glare instrument panel in dark mode.

## Anti-references

Avoid low-contrast text, green-tinted neutrals across the entire page, muddy boundaries between navigation and content, decorative gradients, and saturated color that competes with code. Use h3.dev's light documentation theme as a readability reference without copying its amber identity or layout.

## Design Principles

- Reading comes before decoration.
- Text, code, and navigation have an explicit contrast hierarchy.
- Teal identifies actions and active state instead of coloring every neutral.
- Light and dark themes are designed as equal reading environments.
- Strategy-specific examples carry the product identity through real code.

## Accessibility & Inclusion

Meet WCAG AA contrast for core text, links, controls, and meaningful boundaries in both themes. Do not rely on color alone to communicate state. Preserve visible keyboard focus and reduced-motion preferences.
